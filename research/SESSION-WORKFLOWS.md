# Session workflow helpers

Seven new helpers are **full-only**. Core is now 72 tools (eleven scene helpers, SCENE-TOOLS.md; twelve world helpers, LIVE-WORLD.md); full is 922 (70 helpers + 434 native commands + 418 actions). Switch with standalone `editor_toolset mode=full`, then refresh `tools/list` without an old cursor. Exact live schemas are authoritative; the historical `TOOLS.md` catalog is not regenerated.

## Identity and write boundaries

Saved entity IDs, editor live IDs and runtime KB IDs are different provenance domains. Never derive IDs from placement order or treat saved IDs as persistent after reload. Revalidate complete live ID/owner/prototype tuples before import. No helper edits `.mythscn` bytes, writes process memory, dispatches arbitrary native getters, uses debugger attachment, calls native `loadScenario` or native start-test.

All output writes require explicit confirmation and new caller-approved absolute local paths. Preview writes nothing. Unknown outcomes retain paths and prohibit automatic retries/rollback/cleanup. Offline tests use synthetic data, including fake installations. Separately authorized managed AI installation/binding and observed UI Play/Defeat/Quit are recorded in [live observations](WORKFLOW-LIVE-OBSERVATIONS.md); comprehensive runtime verification remains incomplete.

## Existing typed trigger edits

`editor_trigger_edit` accepts `objectReplacements` and `copyEffects` alongside legacy edits. Source SHA and expected trigger names remain mandatory. Replacements supply complete ordered expected/new `{unitId,player,proto}` tuples and `parameter`, with either original `kind/elementIndex` or copied `copyHandle`.

Copies supply `handle`, `sourceTriggerId`, `expectedSourceName`, `effectIndex`, `beforeEffectIndex`. All batch copy sources are the **original immutable pinned export**, even when another operation edits them. Insertion indices refer to original destination effects; same-position copies preserve request order. Selection flag, trailers, expression extras, unrelated records and groups are verified on readback. Unsupported encodings/self-reference clone hazards refuse. Applying output is still the separately guarded `editor_triggers` workflow, not implicit here.

## Player AI path readback

Guarded player settings accept safe bare saved **expected** AI names such as `chairon`; destinations still require a safe nested installed path. Source expectations remain exact. For explicitly requested AI destinations only, checkpoint verification accepts the observed game omission of a terminal `.xs`; no basename/directory/case/OCR widening or unrequested-field normalization occurs. Long browser search text may fail OCR; stop and inspect, never blindly retry.

Release build, local synthetic self-tests and offline protocol smoke have passed. Protocol uses impossible PID to prove saved queries/generators/refusals require no game connection and verifies core/full switching and hidden-call preflight.
