# Tool sets, discovery and source catalogs

Moved verbatim from AGENTS.md; served by `editor_help topic=catalog`.

- Default core exposes 78 tools (69 helpers + nine essential native commands). Core `editor_call {name, arguments}` calls any hidden full-catalog tool (natives, `action_*`, workflow helpers) without switching: target schema/confirmations preflight as for direct calls, also as a batch step; not for editor_call/editor_batch/editor_toolset. Always-visible `editor_toolset` inspects/switches core/full mid-session; full has 928 tools (including seven full-only session workflow helpers). Changes notify tools/list_changed: refresh tools/list without old cursor. Use standalone mode call, never inside editor_batch. Hidden calls/batch steps fail before effects. Tool sets are not permission sandboxes.
- Find tools from core with `editor_search_tools`: required nonblank `query` (max256), whitespace-separated case-insensitive terms across full-catalog names/descriptions; compact results include `available`/`requiredToolset`/`callVia`; `includeSchema=true` adds inputSchema/annotations (small limit). offset>=0, limit1..50 (default10); follow nextOffset. No game connection, mode change or match execution. Hidden matches: call via `editor_call`, or standalone full switch and fresh tools/list; availability is not runtime readiness.
- For unfamiliar native parameters, read `generated/catalog.json` or narrowly filtered `editor_catalog` (current set only). Switch full when needed; do not page full schema surface for one command. Immutable definitions cached within host.
- Missing/stale catalog metadata (`METADATA_*`/`FILE_NOT_FOUND` from catalog tools): run core `editor_generate_catalog` (no game connection; decodes installed archives with bundled CryBar from `lib/CryBarEditor` submodule; catalog tools reload without restart, new `action_*` tools need restart).
- Use `editor_pantheon` for exact culture-associated unit/building names (e.g. `greeks`), not guessed spellings/artwork. Metadata-only; no game connection. Union across gods/ages, not current-player trainability. Regenerate/restart if metadata missing/stale.
- Use filtered `editor_prototypes` for trees/resources/wildlife/decorations/other objects; `editor_gods`, `editor_technologies`, `editor_god_powers`, `editor_terrain_types`, `editor_water_types` for other source catalogs. Exact `name` or narrow `filter`; bounded `limit`, follow `nextOffset`. XML detail only when needed. Metadata-only batches need no game. Source names/flags are not runtime IDs or placement proof.
- Use `editor_dependencies` for source train/build/tech/god paths; potential links, not evaluated current-player trainability. `editor_validate_scenario` is partial/read-only; caller-declared live IDs and supplied controller heuristics only, skipped checks explicit.
