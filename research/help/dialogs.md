# Editor dialogs and windows

Moved verbatim from AGENTS.md; served by `editor_help topic=dialogs`.

- Use `editor_dialogs` to understand editor windows/menus without screenshots: filter or exact window/open name gives controls (labels, types, value kinds) and the native calls each button/menu item runs as ready `editor_call` `{tool, arguments}`. Wrapper→XML window links: `live` (alt UI observed), `xml`, `name` (unobserved). Value fields without scripts have no native setter. Metadata only; regenerate if missing/stale.
- Live dialogs: `editor_dialog_state` detects open dialogs by calibrated pixel signatures (`uilayouts/dialogs-*.json`; normal UI 2560×1440 only so far, default window position) and maps `editor_dialogs` controls to client rects; `read=true` adds OCR text and a green-tick checkbox heuristic. `editor_dialog_act` open/close/press/select run shipped scripts as validated native calls (view-only gadget scripts and Close/Cancel unconfirmed, else confirmDestructive); click/setText/toggle are pixel input after OCR label verification and refuse on uncalibrated size, moved/occluded windows. setText never sends TAB/ENTER/ESC/Ctrl+A; nothing applies until the dialog's own OK/Generate. Live-verified normal 2560×1440: New Scenario/Victory Conditions/Player Data open+read+close, Seed setText (-1→777→-1); alternative UI and other sizes uncalibrated (state reports no signatures, pixel actions refuse). Field text comes from per-control OCR (zoom 2, then 3; `textSource`); focused-field caret can hide short text, so setText verify re-reads up to 3 frames (`framesRead`), never re-types. Observations only; checkpoint stays authoritative.
- Open editor windows with `editor_gadgetReal` names listed in its description (live-verified normal and alternative UI; e.g. `PlayerEditDlg`; `PlayerDataDialog` is an empty shell). Close with `editor_gadgetUnreal` and the same name (alternative UI exceptions: `DiplomacyDialog` → `PlayerDiplomacyDialog`, `ATriggerGadget` → `trEditor`); `uiCloseDialog` did not close them. Acknowledgement is not proof: screenshot.
