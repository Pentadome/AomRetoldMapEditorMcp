# Players, diagnostics and error handling

Moved verbatim from AGENTS.md; served by `editor_help topic=players`.

- Start unfamiliar work with `editor_capabilities`. Errors carry `code`/`nativeDispatched`/`safeInspection`/`nextAction`; `*_OUTCOME_UNKNOWN` means stop and inspect retained paths. Campaign triggers: `editor_trigger_list` then preview-first `editor_trigger_edit` (expectedSha256+expectedName, new outputPath); `editor_triggers apply` also needs reviewed live export path/hash. Players: `editor_players`/`editor_player_dependency_audit` decode reviewed checkpoint fields; stances 1 ally, 2 enemy, 3 neutral. `editor_set_diplomacy` accepts directed matrix `changes` (one final checkpoint) as well as legacy oneWay/mutual. `editor_player_settings` previews/verifies offline; apply is pinned to 2560×1440 or 1920×1080 alternative Players Settings or normal Player Data, pixel/OCR gates, fresh checkpoint/TR backups and game-written final checkpoint. Normal UI live-verified: name/resources/pop/handicap, control/visibility, civ (scrolling list), color (`swatchRgb` sampled at x=88), start/max age, minor god, AI path (Set needs control Computer), and diplomacy matrix. Player `name` = editable display name (first PL string, `displayName` in `editor_players`). Normal text fields keep a blinking caret, so OCR gates re-read; startAge 0 may show "Default". MCP input refuses outside editor mode, so main-menu settings toggle required a temporary PID/foreground/size-guarded menu-only click helper, with MCP screenshots. Returning to Editor starts blank; restore backup via visible Load Scenario UI (never native `loadScenario`). After reload PL and embedded TR matched `step-03`; trigger export bodies and named camera entries matched too, with only the export-basename header changed. Exact viewport pose was not restored. Age changes auto-reset minor gods: require `observedOnly` assertions for all three; AI Name UI typing did not persist, but guarded file browser can reselect profile `<id>\Game\AI` (or stock `game\ai`) XS and verify checkpoint. OCR '9' may read as '6' or reversed—checkpoint is authoritative, never retry blindly.
